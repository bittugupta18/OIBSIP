# BMI Calculator

## About
This is a simple BMI Calculator developed using Python.
It calculates the Body Mass Index (BMI) based on the user's
weight and height and displays the corresponding BMI category.

## Features
- Takes weight in kilograms
- Takes height in meters
- Calculates BMI
- Displays BMI category
- Rounds BMI to 2 decimal places
- Handles invalid input
- Handles negative and zero values

## Technologies Used
- Python 3

## BMI Categories
- Underweight: BMI below 18.5
- Normal: BMI 18.5 - 24.9
- Overweight: BMI 25 - 29.9
- Obese: BMI 30 or above

## How to Run

1. Install Python 3.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run:

python bmi_calculator.py

5. Enter your weight and height when prompted.
